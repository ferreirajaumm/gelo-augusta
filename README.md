# Gelo Augusta — site institucional

Site estático preparado para publicação na Vercel.

## Incluído na publicação

- `index.html`, `styles.css`, `script.js` e `tracking.js`
- Fotografias reais em `assets/`
- Favicon e configurações de hospedagem (`vercel.json`)
- Plano de mensuração (`MEASUREMENT_PLAN.md`)

## Publicação

A Vercel detecta este projeto como estático. Não há etapa de build nem dependências obrigatórias.

Antes de ativar rastreadores em produção, preencha somente os IDs reais em `window.GELO_TRACKING_CONFIG`, em `index.html`.
